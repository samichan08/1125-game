# STAR DODGER

HTML 1ページ完結でブラウザ上ですぐに遊べる、レトロアーケード風の縦スクロール回避ゲームです。  
次々と迫りくる4種類の敵をすり抜けながら、どこまで遠くへ飛べるか（走行距離）を競います。

---

## 遊び方（操作方法）

### 起動方法
`index.html` をダブルクリックするなどして、PCのWebブラウザで開くだけでプレイできます（サーバーや追加ファイルのインストールは不要です）。

### キーボード操作
| キー | アクション |
| :--- | :--- |
| `←` `→` `↑` `↓` または `W` `A` `S` `D` | 自機の移動（上下左右・斜め8方向） |
| `Space` または `Shift` | **ブーストダッシュ**（短時間の無敵＋高速移動 ※クールタイムあり） |
| `Enter` | ゲームスタート / リトライ / ポーズ解除 |
| `P` | ポーズ（一時停止 / 再開） |
| `R` | リスタート |
| `M` | 効果音のミュート切り替え（ON / OFF） |

### ルールとギミック
- **敵の回避**: 上から迫る敵にぶつかるとゲームオーバー（シールド所持時は1回だけ防御可能）。距離が進むと `SPEED LV` が上がり、敵の出現ペースや速度が上昇します。
  - **直進型**: まっすぐ降下してくる基本の敵
  - **ジグザグ型**: 左右に揺れながら降下する敵（LV2〜）
  - **高速突撃型**: 上端に警告ライン（`!`）が出た後、高速で縦断してくる敵（LV2〜）
  - **大型メテオ**: 回転しながら落ちてくる大きな障害物
- **アイテム**:
  - **シールド（水色 `S`）**: バリアを展開し、被弾を1回防ぎます（既に所持している場合は `+150m` ボーナス）。
  - **エネルギーコア（黄色）**: 取得すると距離ボーナス `+100m`。
- **ニアミス（GRAZE）**: 敵のギリギリ横をすり抜けると、火花エフェクトとともに `+25m` ボーナスが加算されます。

## 工夫した点

- **HTML 1ファイルで完結する構成**
  - Canvas API による描画と Web Audio API によるレトロ電子音（スタート音、ブースト、アイテム取得、シールド破壊、ニアミス、クラッシュ音など）をすべて `index.html` 内に実装し、外部アセットなしで動作するようにしました。
- **アーケード筐体風のビジュアル・演出**
  - CRTスキャンライン風のオーバーレイ、ネオンカラーの筐体枠、3層の流れる星空とサイバーグリッド、被弾時の画面シェイクやパーティクル演出を取り入れました。
- **避けゲーとしての操作感・戦略性**
  - 見た目より少し小さめの円形当たり判定（半径 9px）を設定し、理不尽な被弾を減らしています。
  - 緊急回避用の「ブーストダッシュ（クールタイムゲージ付き）」や「ニアミス（GRAZE）ボーナス」を用意し、ただ逃げるだけでなく攻めの回避が楽しめるようにしました。
  - ハイスコア（`HI-SCORE`）は `localStorage` に自動保存されます。
